# Chronosphere geographic assets

Production assets are generated by `npm run build:geo`.

The pipeline uses Natural Earth 5.1.1 Admin-0 data:

- 50m Admin-0 countries for the global layer.
- 10m Admin-0 countries for the detailed layer.
- Natural Earth India POV geometry applied consistently to India in both LODs.
- Natural Earth disputed-boundary lines as a separate dashed overlay.
- TopoJSON quantization/simplification at build time.
- Shared topology for merged WebGL line buffers.

The runtime looks for:

- `/geo/world-50m.topojson`
- `/geo/world-10m.topojson`
- `/geo/disputed-boundaries-10m.topojson`

If the production assets are absent during development, the browser can fall back to Natural Earth's remote sources. The development fallback also fetches the India POV dataset so the India worldview remains consistent.

For production, run:

```text
npm install
npm run build:geo
npm test
npm start
```

Boundary policy: Natural Earth default de-facto boundaries, with India using the Natural Earth India POV variant and disputed boundaries shown separately.
